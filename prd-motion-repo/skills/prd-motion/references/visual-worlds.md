# 시각 세계 정하기

PRD의 도메인 현장에 실제로 있는 사물에서 색, 글꼴, 형태를 가져온다. 목표는 도메인 사람이 보자마자 "우리 현장 같다"고 느끼는 것이다. 흔한 AI 디자인(보라→파랑 그라데이션, 크림색 배경에 세리프, 모든 것 가운데 정렬, 이모지 섹션 표시)은 피한다.

## 정하는 순서

1. PRD에서 현장의 물건 3개를 고른다. 사용자가 매일 보는 표지판, 화면, 서류, 장비를 찾는다.
2. 그중 하나를 **시그니처 요소**로 정한다. 섹션 라벨, 보드, 숫자 표시에 반복해서 쓴다. 공항의 노란 게이트 표지, 출발 안내판 같은 것이다.
3. 강조색은 그 물건의 색에서 가져온다. 의미 색(정상, 주의, 위험)은 강조색과 겹치지 않게 따로 둔다.
4. 글꼴은 세 역할로 정한다. 표시용(굵은 한글 고딕), 본문(IBM Plex Sans KR, Noto Sans KR, Pretendard 대체 등), 데이터용(고정폭 + 한글 대체 글꼴)이다.
5. 어두운 바탕과 밝은 바탕은 현장에 맞춰 고른다. 관제실과 공항은 어둡게, 병원 서류와 B2B 업무 도구는 밝게 하는 식이다. 사용자가 회사 브랜드 스킬(예: gsrr-design)을 지정하면 그 토큰을 우선한다.

## 예시

| 도메인 | 시그니처 요소 | 바탕 / 강조 | 데이터 표시 |
|---|---|---|---|
| 공항·교통 | 노란 게이트 표지, 출발 안내판 글자 넘김 | 숯색 / 사인 옐로 | 고정폭, 안내판 행 |
| 병원·헬스케어 | 활력징후 모니터 파형, 환자 팔찌 | 짙은 청록 또는 흰 차트 / 모니터 그린 | 파형 스파크라인, 바이탈 숫자 |
| 물류·커머스 | 송장 라벨, 바코드, 팔레트 | 크라프트 톤 또는 흰색 / 라벨 오렌지 | 바코드 패턴 구분선, 운송장 번호 |
| 금융·결제 | 체결 시세판, 영수증 | 남색 / 상승 레드, 하락 블루(국내 관례) | 숫자 틱 애니메이션 |
| 제조·설비 | 안돈 표시등, 공정 라인 | 공장 회색 / 안전 옐로·블랙 사선 | 공정 단계 타일, 가동률 게이지 |
| 리테일·매장 | 진열대 POP, 영수증, 가격표 | 브랜드색 | 가격표 숫자, 진열 칸 그리드 |
| 교육·HR | 시간표, 출석부, 수료증 | 밝은 종이 톤 / 잉크 블루 | 시간표 격자 |
| 공공·민원 | 번호표 발권기, 창구 호출 표시기 | 짙은 남색 / 호출 레드 디지털 숫자 | 7세그먼트 느낌 숫자 |
| SaaS·개발 도구 | 터미널, 대시보드 카드, 상태 배지 | 밝은 회색 / 브랜드 블루 | 상태 배지, 로그 줄 |

## 토큰 블록 예시 (어두운 현장)

```css
/* Layout: <현장> 사인물 문법. 기능마다 움직이는 도면 한 장 + 조작 패널 한 쌍. */
:root{
  --bg:#0b1016; --panel:#111923; --panel2:#172231; --line:rgba(170,195,230,.15);
  --ink:#eef2f7; --mute:#8d9aac;
  --sign:#ffc629; --sign-ink:#15120a;          /* 시그니처 강조색 */
  --flow:#3ed6b5; --warn:#ff9f40; --alert:#ff5a4f; --info:#5aa9ff; /* 의미 색 */
  --f-d:'Gothic A1','IBM Plex Sans KR',system-ui,sans-serif;
  --f-b:'IBM Plex Sans KR',system-ui,sans-serif;
  --f-m:'JetBrains Mono','IBM Plex Sans KR',ui-monospace,monospace;
  color-scheme:dark;
}
```

한 가지 모습으로 통일한 디자인(어두운 관제실 톤 등)은 다크/라이트 두 테마를 만들지 않아도 된다. 대신 `body` 배경과 모든 색을 명시하고, 어두운 톤이면 `color-scheme:dark`를 둔다. 밝은 현장이면 밝은 토큰을 기본으로 하고, 다크 모드 블록을 함께 정의한다.
